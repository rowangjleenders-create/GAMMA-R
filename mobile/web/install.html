Quick path — Expo Go

Recommended to try first
  1. Install Expo Go (button above, or search the App Store / Play Store).
  2. Open Expo Go and scan the QR code from your developer’s Expo start screen, or tap the project link below.
  3. In the app, open Settings and enter your API server address (example: http://192.168.1.10:8000).
  4. You’re done — Scan, Portfolio, and Watchlist talk to your server.

Permanent path — standalone app

No Expo Go needed
  1. Download the Android APK or iOS IPA from the buttons below (after your developer publishes a build).
  2. Install it (Android: open the APK file; iOS: needs a signed IPA / TestFlight — Apple developer account required).
  3. Open GAMMA-R → Settings → enter your API server address.
  4. Done — same features, as a normal app icon.

After install

The app does not ship with a public trading server. Someone must run the GAMMA-R API (same Wi‑Fi / VPN / public host), then you type that address in Settings.
